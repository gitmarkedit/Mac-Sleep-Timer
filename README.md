# 🌙 Mac Sleep Timer

> Удобный терминальный таймер перехода в режим сна для **macOS** с интерактивным TUI-интерфейсом, готовыми кнопками выбора и обратным отсчетом.

---

## ✨ Возможности

- 🎮 **Интерактивный терминальный интерфейс (TUI)**: красивый дизайн в стиле retro-терминалов с рамками, цветами и индикаторами.
- 🔘 **Быстрые кнопки пресетов**: выбор стрелками `↑ / ↓`, цифрами `1–7` или `Enter`.
  - `[ 1 ]` — 15 минут
  - `[ 2 ]` — 30 минут (полчаса) *(по умолчанию)*
  - `[ 3 ]` — 45 минут
  - `[ 4 ]` — 1 час (60 мин)
  - `[ 5 ]` — 1.5 часа (90 мин)
  - `[ 6 ]` — 2 часа (120 мин)
  - `[ 7 ]` — Своё время... (ручной ввод в любых форматах: `25m`, `1.5h`, `1ч 30мин`, `0:45`)
- 📊 **Экран активного таймера**:
  - Точное время засыпания (например, `Mac уснет в 22:30:00`)
  - Крупный таймер оставшегося времени
  - Графический прогресс-бар в реальном времени (`[████████░░░░░░░░] 48%`)
- ⌨️ **Горячие клавиши на лету**:
  - `[Пробел]` — Пауза / Возобновление
  - `[ + ]` — Добавить +5 минут
  - `[ - ]` — Убавить -5 минут
  - `[ S ]` — Усыпить Mac прямо сейчас
  - `[ Q / Esc]` — Отмена и выход
- 🔔 **Системные уведомления**: нативные push-уведомления macOS при старте и завершении, а также звуковое предупреждение за 15 секунд до сна.
- 📦 **Zero Dependencies**: работает на чистом Python 3 без установки сторонних библиотек.

## 🖥 Предпросмотр интерфейса

### Главное меню:
```text
 ╭────────────────────────────────────────────────────────────╮
 │  🌙  MAC SLEEP TIMER  •  Таймер перехода в режим сна       │
 ╰────────────────────────────────────────────────────────────╯

  Выберите готовый вариант или укажите своё время:

    [ 1 ] 15 минут               │ Быстрый перерыв / фоновое аудио
  ▸ [ 2 ] 30 минут (полчаса)     │ Оптимально перед сном
    [ 3 ] 45 минут               │ Серия сериала или подкаст
    [ 4 ] 1 час (60 мин)         │ Альбом или аудиокнига
    [ 5 ] 1.5 часа (90 мин)      │ Полнометражный фильм
    [ 6 ] 2 часа (120 мин)       │ Длительный плейлист
    [ 7 ] Свое время...          │ Ввести минуты или часы вручную

 ╭────────────────────────────────────────────────────────────╮
 │ ↑ / ↓ или [1-7] — выбор   [Enter] — старт   [Q / Esc] — выход │
 ╰────────────────────────────────────────────────────────────╯
```

### Экран активного таймера:
```text
 ╭────────────────────────────────────────────────────────────╮
 │  🌙  MAC SLEEP TIMER  •   🟢 ТАЙМЕР АКТИВЕН                │
 ╰────────────────────────────────────────────────────────────╯

  Осталось времени:       00:28:45    (всего: 30:00)
  Время засыпания:        22:15:30    (прошло: 01:15)

  [████████████████░░░░░░░░░░░░░░░░░░░]   4.2%

 ╭────────────────────────────────────────────────────────────╮
 │ [Space] Пауза/Пуск   [ + ] +5 мин    [ - ] -5 мин          │
 │ [ S ]   Усыпить сейчас          [Q / Esc] Отмена и выход   │
 ╰────────────────────────────────────────────────────────────╯
```

## 🚀 Быстрый запуск

### 1. Интерактивный запуск (меню):
```bash
./sleepmac
```

### 2. Прямой запуск на заданное время:
```bash
./sleepmac 30m     # Mac уснет через 30 минут
./sleepmac 1h      # Mac уснет через 1 час
./sleepmac 45      # Mac уснет через 45 минут
./sleepmac 1.5h    # Mac уснет через 1.5 часа
./sleepmac 1:30    # 1 час 30 минут
```

### 3. Режим тестирования (Dry-Run):
```bash
./sleepmac 10s --dry-run
```
*Таймер отрабатывает вживую, но команда сна `pmset sleepnow` не вызывается.*
