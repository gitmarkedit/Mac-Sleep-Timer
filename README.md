> Удобный, надёжный и красивый таймер перехода в режим сна для **macOS**. Работает как интерактивное терминальное TUI-приложение, консольная утилита и нативное приложение с иконкой.

Поддерживает все версии macOS (Monterey, Ventura, Sonoma, Sequoia) на процессорах **Apple Silicon (M1/M2/M3/M4)** и **Intel**.

---

## ⚡️ Быстрая установка на любом Mac

Склонируйте репозиторий и запустите скрипт установки:

```bash
git clone https://github.com/gitmarkedit/Mac-Sleep-Timer.git
cd Mac-Sleep-Timer
./install.sh
```

Скрипт автоматически:
1. Установит команду `sleepmac` в систему (вы сможете вызывать её из любого места терминала).
2. Соберет нативное приложение **«Таймер сна.app»** прямо на вашем компьютере с актуальной подписью и установит его в папку `Программы` (`/Applications`).

Также проект можно установить через **pip / pipx**:
```bash
pip install .
```
или через **Makefile**:
```bash
make install
```

## ✨ Возможности

- 🎮 **Интерактивный терминальный интерфейс (TUI)**: дизайн в стиле современных терминалов с рамками, цветами и индикаторами.
- 🔘 **Быстрые кнопки пресетов**: выбор стрелками `↑ / ↓`, цифрами `1–7` или `Enter`.
  - `[ 1 ]` — 15 минут
  - `[ 2 ]` — 30 минут (полчаса) *(по умолчанию)*
  - `[ 3 ]` — 45 минут
  - `[ 4 ]` — 1 час (60 мин)
  - `[ 5 ]` — 1.5 часа (90 мин)
  - `[ 6 ]` — 2 часа (120 мин)
  - `[ 7 ]` — Своё время... (ручной ввод в любых форматах: `25`, `45m`, `1.5h`, `1ч 30мин`, `0:45`)
- 📊 **Экран активного таймера**:
  - Точное время засыпания (например: `Mac уснет в 22:30:00`)
  - Крупный счетчик оставшегося времени
  - Живой прогресс-бар в реальном времени (`[████████░░░░░░░░] 48%`)
- ⌨️ **Горячие клавиши на лету**:
  - `[Пробел]` — Пауза / Возобновление
  - `[ + ]` — Добавить +5 минут прямо во время отсчета
  - `[ - ]` — Убавить -5 минут
  - `[ S ]` — Усыпить Mac немедленно
  - `[ Q / Esc]` — Отмена и выход
- 🔔 **Уведомления и звук**: нативные push-уведомления macOS при старте и завершении, а также звуковое предупреждение терминала за 15 секунд до сна.
- 📦 **Zero External Dependencies**: работает на чистом встроенном Python 3 без необходимости ставить сторонние библиотеки.

## 🖥 Предпросмотр терминального интерфейса

### Главное меню:
```text
 ╭────────────────────────────────────────────────────────────╮
 │  🌙  MAC SLEEP TIMER  •  Таймер перехода в режим сна       │
 ╰────────────────────────────────────────────────────────────╯

  Выберите готовый вариант или укажите своё время:

    [ 1 ] 15 минут               │ Быстрый перерыв / фоновое аудио
  ▸ [ 2 ] 30 минут (полчаса)     │ Оптимально перед сном
    [ 3 ] 45 минут               │ Серия сериала или подкаст
    [ 4 ] 1 час (60 мин)         │ Альбом или аудиокнига
    [ 5 ] 1.5 часа (90 мин)      │ Полнометражный фильм
    [ 6 ] 2 часа (120 мин)       │ Длительный плейлист
    [ 7 ] Свое время...          │ Ввести минуты или часы вручную

 ╭────────────────────────────────────────────────────────────╮
 │ ↑ / ↓ или [1-7] — выбор   [Enter] — старт   [Q / Esc] — выход │
 ╰────────────────────────────────────────────────────────────╯
```

### Экран активного таймера:
```text
 ╭────────────────────────────────────────────────────────────╮
 │  🌙  MAC SLEEP TIMER  •   🟢 ТАЙМЕР АКТИВЕН                │
 ╰────────────────────────────────────────────────────────────╯

  Осталось времени:       00:28:45    (всего: 30:00)
  Время засыпания:        22:15:30    (прошло: 01:15)

  [████████████████░░░░░░░░░░░░░░░░░░░]   4.2%

 ╭────────────────────────────────────────────────────────────╮
 │ [Space] Пауза/Пуск   [ + ] +5 мин    [ - ] -5 мин          │
 │ [ S ]   Усыпить сейчас          [Q / Esc] Отмена и выход   │
 ╰────────────────────────────────────────────────────────────╯
```

## 🚀 Примеры использования

### 1. Интерактивный запуск (TUI-меню):
```bash
sleepmac
```

### 2. Прямой запуск на заданное время (без открытия меню):
```bash
sleepmac 30m     # Mac уснет через 30 минут
sleepmac 1h      # Mac уснет через 1 час
sleepmac 45      # Mac уснет через 45 минут
sleepmac 1.5h    # Mac уснет через 1.5 часа
sleepmac 1:30    # 1 час 30 минут
```

### 3. Режим тестирования (Dry-Run):
```bash
sleepmac 10s --dry-run
```
*Таймер отрабатывает вживую, но команда сна `pmset sleepnow` не вызывается.*

## 🍏 Нативное приложение macOS

Вместе с консольной утилитой поставляется графическое приложение **«Таймер сна.app»**:
- Доступно в папке **«Программы»** (`/Applications`), Spotlight и Launchpad после запуска `./install.sh`.
- Можно вызывать мышкой в один клик без терминала.
- При необходимости приложение можно пересобрать вручную:
  ```bash
  ./build_app.sh
  ```
